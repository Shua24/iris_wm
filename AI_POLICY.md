# Iris WM AI Policy

Here is an AI policy for contributing to the Iris Window Manager project.

### 1. Types of Prohibited Agents

Agents that are not allowed to contribute to the Iris Window Manager project
are as follows:

1. Agents that run a full Github account.
2. Agents running without a human supervision, also knmown as rogue agents
set up by a developer.

These points of prohibition are there to prevent rogue agents from contributing
to the project, as we don't want to have the wrong trajectory of changes or
break the project. Rogue agents that violate these points will be blocked from
contributing to the project altogether, permanently.

### 2. Absolute Prohibitions

AI agents are prohibited from these operations under any circumstances:

1. Filing pull requests without human supervision
2. Contributing to the SPARK codebase
3. Requesting new features into GitHub or any Git repository hosting services
that host this project. 

### 3. General Prohibition

AI agents are not recommended to do these operaions as a general rule:

1. Pushing commits to GitHub or any Git repository hosting services that host
this project.
2. Filing issues to GitHub or any Git repository hosting services that host
this project.
